# Troubleshooting

## Pexels footage is unavailable

Store your real Pexels API key only in the local `.env` file.

Never commit the `.env` file to GitHub.

## Narration sounds robotic

Use Kokoro Local and preview the narrator before rendering.

Recommended speed: 0.92.

## Captions fail on macOS

Install FFmpeg Full with `brew install ffmpeg-full`.
